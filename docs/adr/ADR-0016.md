# ADR-0016: Public repository, all rights reserved, not open source during alpha

- Status: Accepted
- Date: 2026-10-26
- Deciders: Rommel

## Context

The repository is public so the work can be shown and evaluated, but the framework is in alpha and its commercial model is undecided. An open source license would be hard to take back.

## Decision

- `LICENSE` states copyright (Rommel Abesames), all rights reserved, alpha status, and that no use is licensed. Companies that adopt RADD get separate written terms from the copyright holder.
- Outside pull requests require a contributor agreement first, so the license can change later.
- npm packages are `private: true` with `"license": "UNLICENSED"`; .NET projects are not packable. No open source license text is added anywhere.
- Moving to a source-available or open source license (for example PolyForm, Business Source License, MIT or Apache 2.0) is revisited at beta, with its own ADR.

## Alternatives considered

- **Open source now.** Irreversible for released versions before the model is decided.
- **Private repository.** Hides the work from evaluators and adopters.
- **Source-available now.** Premature until the intended use cases are clear.

## Consequences

- Nobody may use RADD without written terms during alpha.
- Third-party dependencies must have licenses compatible with any future choice (permissive licenses only).
