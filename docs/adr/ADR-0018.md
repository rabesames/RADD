# ADR-0018: Target the latest long-term-support releases

- Status: Accepted
- Date: 2026-10-26
- Deciders: Rommel

## Context

Adopting companies run supported platforms, and the framework should not ship on versions that leave support soon after alpha.

## Decision

- Always target the latest LTS releases. Today: .NET 10 with EF Core 10 (supported to November 2028) and Node.js 26 (Active LTS from October 28, 2026, supported to April 2029). Node 24 LTS is acceptable until then.
- `package.json` files declare `"engines": { "node": ">=24" }`; CI runs on Node 24 and 26. `dotnet/global.json` pins SDK 10.0 with `latestFeature` roll-forward.
- Short-term releases (for example .NET 11) are not targeted.
- Moving to a newer LTS is its own ADR.

## Alternatives considered

- **Latest releases including STS.** Shorter support windows for adopters.
- **Older LTS for compatibility.** Loses features and shortens the remaining support period.

## Consequences

- Node 24 support can be dropped by a later ADR once Node 26 is established.
