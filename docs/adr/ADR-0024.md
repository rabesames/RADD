# ADR-0024: The first stack is React + TypeScript, ASP.NET Core with EF Core, and SQLite

- Status: Accepted
- Date: 2026-10-26
- Deciders: Rommel

## Context

The framework needs one complete stack to prove the design end to end before others are added.

## Decision

v1 targets React + TypeScript on the front end, C# / ASP.NET Core with EF Core on the backend, and SQLite as the database. Java, Python, SQL Server, Postgres and others follow later without changing the dictionary format; the design must not block them.

## Alternatives considered

- **SQL Server or Postgres first.** Heavier local setup; SQLite runs everywhere with no server and exercises EF's table-rebuild path for unsupported ALTERs.
- **Several stacks at once.** Slower to prove the design.

## Consequences

- The dictionary schema already lists `sqlserver` and `postgres` as database providers, so database-computed SQL can be written for them.
- Type mappings and conformance vectors start with SQLite only.
