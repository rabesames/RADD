# ADR-0019: GitHub Actions for CI

- Status: Accepted
- Date: 2026-10-26
- Deciders: Rommel

## Context

Every stage's tests must run automatically on every pull request, and the repository is on GitHub.

## Decision

CI runs on GitHub Actions (`.github/workflows/ci.yml`). Every stage's tests run in CI: the TypeScript build, Biome check and tests on Ubuntu and Windows with Node 24 and 26; the .NET build; linting the example dictionary; and the ADR check on pull requests.

## Alternatives considered

- **Azure Pipelines, GitLab CI or others.** Extra accounts and configuration for a GitHub-hosted repository.

## Consequences

- Workflow actions are pinned to major versions and updated deliberately.
- The ADR check is made a required status check on `main` (ADR-0034).
