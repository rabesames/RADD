# ADR-0033: Locales are declared by the dictionary

- Status: Accepted
- Date: 2026-10-26
- Deciders: Rommel

## Context

The spec listed the default locale in `dictionary.yaml` and also `locales: { default, supported }` in `radd.config.yaml`. Lint needs the supported locales to check translations, and the canonical JSON carries the messages for each.

## Decision

`dictionary.yaml` declares `locales: { default, supported }`. The `locales` entry in `radd.config.yaml` is dropped when stage 8 (CLI and initializer) is detailed. Lint requires the default locale to be in the supported list, a file in `i18n/` for every supported locale, and no files for other locales (RADD505).

## Alternatives considered

- **Locales in the project config.** The dictionary would not be self-contained, and lint and build would need the config.

## Consequences

- The dictionary folder is complete on its own: it can be linted and built without a project config.
