# ADR-0017: Naming: RADD, radd, RADD.*, @radd/*, /_radd, RADD-* headers, radd.* keys

- Status: Accepted
- Date: 2026-10-26
- Deciders: Rommel

## Context

The framework's name appears in packages, commands, URLs, headers, message keys and code. Consistency makes it recognizable and avoids collisions with application names.

## Decision

| Where | Name |
| --- | --- |
| Framework | RADD |
| CLI | `radd` |
| NuGet packages | `RADD.*` (`RADD.Core`, `RADD.Generators`, `RADD.EntityFrameworkCore`, `RADD.AspNetCore`) |
| npm packages | `@radd/*` (`@radd/core`, `@radd/cli`, `@radd/client`) |
| Endpoints | `/_radd/*` |
| Headers | `RADD-Version`, `RADD-Acknowledge` |
| Framework message keys | `radd.*` (reserved: a dictionary cannot define an entity, domain type or lookup whose key prefix is `radd`) |

Both the `RADD.*` NuGet prefix and the `@radd` npm scope need an availability check before anything is published.

## Alternatives considered

- Other names were not formally evaluated; RADD was chosen by Rommel.

## Consequences

- Lint reserves the `radd` message-key prefix (RADD103).
