# ADR-0011: Each dictionary serves exactly one system

- Status: Accepted
- Date: 2026-10-26
- Deciders: Rommel

## Context

Organizations with several services might want one shared dictionary. Sharing raises versioning, ownership and deployment-coupling questions that would dominate v1.

## Decision

Each dictionary serves exactly one system (one API and its front ends). Sharing one dictionary across several systems or services is out of scope.

## Alternatives considered

- **A shared, organization-wide dictionary.** Couples deployments, needs cross-service versioning and ownership rules.
- **Imports between dictionaries.** Adds a module system to the format before the basics are proven.

## Consequences

- The dictionary version (its hash) identifies one system's model.
- Services that need the same concepts duplicate them, or a later ADR introduces sharing.
