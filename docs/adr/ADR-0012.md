# ADR-0012: No generic CRUD endpoints

- Status: Accepted
- Date: 2026-10-26
- Deciders: Rommel

## Context

With the full model in the dictionary, the framework could expose generic create, read, update and delete endpoints for every entity.

## Decision

The framework offers no generic CRUD endpoints for now. Application endpoints stay the developer's; RADD validates their payloads (endpoint or action filter) and every save (SaveChanges interceptor). Its own endpoints are limited to `/_radd/metadata`, `/_radd/lookups` and `/_radd/validate`.

## Alternatives considered

- **Generic CRUD.** Fast to start, but it bypasses authorization, business logic and API design that belong to the application, and becomes an attack surface.

## Consequences

- Developers write their endpoints as usual and get validation for free.
- Generic CRUD can be revisited with its own ADR.
