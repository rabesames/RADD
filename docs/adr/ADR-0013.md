# ADR-0013: No hot reload of the dictionary

- Status: Accepted
- Date: 2026-10-26
- Deciders: Rommel

## Context

Reloading the dictionary in a running API would let changes apply without a restart, but the EF model, generated classes and caches are built once at startup.

## Decision

There is no hot reload. Dictionary changes take effect on rebuild and restart; `dotnet watch` covers this in development.

## Alternatives considered

- **Hot reload.** EF Core's model cannot change at run time, generated entity classes need a rebuild, and partially applied changes would be hard to reason about.

## Consequences

- The dictionary embedded at build time is the one that runs; its hash is the version every response reports.
- Clients detect a new version through `RADD-Version` after a deployment (ADR-0004).
